# Registro de cambios

## 0.1.2

- Primera adaptación experimental a Linux Mint 22.x amd64 y paquete .deb.
- Apertura de carpetas descargadas mediante xdg-open.
- Ventana Linux con una sola vista web y permisos de zoom limitados.
- Compilación y comprobación de arranque en GitHub Actions para Ubuntu 24.04.

## 0.1.1

- Instalador único de Windows 11 x64 con el instalador completo de WebView2 incluido para los equipos que lo necesiten.
- Autoría y editor identificados como NEO0325L.
- Código original bajo licencia MIT, con créditos y avisos de dependencias incluidos en la distribución.
- Selector de idioma español/inglés en el instalador.

## 0.1.0

Primera publicación experimental: WhatsApp Web incrustado, sesión persistente, ventana redimensionable, adjuntos, descargas con apertura del Explorador, zoom y atajo de emojis.
